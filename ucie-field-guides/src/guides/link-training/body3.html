14 · Test yourself

Interview-style questions.

List the top-level LTSM states in bring-up order. Basic

RESET → SBINIT → MBINIT → MBTRAIN → LINKINIT → ACTIVE. Plus PHYRETRAIN, L1/L2 and TRAINERROR off the main path.

SpecFigure 4-33, p.131

Which states have no 8 ms timeout? Basic

RESET, ACTIVE, L1/L2 and TRAINERROR. All others time out after 8 ms, counted per sub-state, and the timer resets on a Stall message.

Spec§4.5, p.124

Why is MBINIT done at 4 GT/s? Basic

Lowest speed, widest eye: an untrained link works, so clock, valid and data lanes can be checked for opens, shorts and reversal, and Vref set, before the harder calibration at the target speed.

SpecTable 4-6, p.131

How does SBINIT cope with two dies leaving reset at different times? Intermediate

A die that detects the pattern sends four more iterations before stopping; a die that detects nothing alternates 1 ms sending and 1 ms quiet for up to 8 ms. Then both exchange {SBINIT Out of Reset} until each has received it.

Spec§4.5.3.2, p.134

Why are clock and valid repaired before data lanes? Intermediate

Data is sampled with the forwarded clock and framed by valid. With a broken clock every data lane would look broken. REVERSALMB is only entered if clock and valid work.

Spec§4.5.3.3.5, p.151

What does DATATRAINCENTER2 do that DATATRAINCENTER1 didn't? Intermediate

Recenters the clock on the aggregate data after the partner performed per-lane deskew in RXDESKEW, which shifted the combined eye.

Spec§4.5.3.4.11, p.164

LINKSPEED finds errors. What are the three outcomes and their order of preference? Advanced

Repair (Advanced, if redundant lanes are enough) or width degrade (Standard, if failures are in one half) → MBTRAIN.REPAIR; otherwise speed degrade → SPEEDIDLE at the next lower rate (TRAINERROR if already 4 GT/s). A speed-degrade request overrides an outstanding repair request. A Runtime Link Test Control change instead sends it to PHYRETRAIN.

Spec§4.5.3.4.12, p.164–167

Die 0 sends retrain encoding 001b, Die 1 sends 100b. Where do they go? Advanced

Both resolve to 100b and go to MBTRAIN.REPAIR. The more severe request always wins: 010b (speed degrade) over 100b (repair) over 001b.

SpecTable 4-12, p.169

Where does each of L1 exit and L2 exit land, and why the difference? Advanced

L1 → MBTRAIN.SPEEDIDLE, restoring the last ACTIVE speed: settings survive, so only speed-dependent calibration repeats. L2 → RESET: deeper power-down may lose state, so full training (≥ 4 ms RESET included) and a fresh Adapter parameter exchange follow.

Spec§4.5.3.9, p.172 · §4.5.3.4.3, p.158

Why must the LTSM stay in TRAINERROR while RDI is in LinkError? Advanced

LinkError means software has to handle the error first (for example DPC). Retraining underneath would bring the link up before software allows it. Once RDI leaves LinkError, the LTSM may go to RESET.

Spec§4.5.3.8, p.171
