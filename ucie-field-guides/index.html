Spec notes found while building the guides

Places where the spec is easy to misread or appears inconsistent. Each is explained in the linked guide.

Gotcha

Three encodings for link width

Code 2h means x64 in Link Capability, but x16 in Link Control and Link Status. Each register has its own table.

SpecTables 9-8, 9-9, 9-10, p.466–470 · Registers guide

Gotcha

PCIe Link Status shows a fixed 8 GT/s x16

On UCIe ports the PCIe capability reports fixed speed and width; the real values are in the UCIe Link DVSEC.

SpecAppendix A.2, Table A-2, p.583 · Registers guide

Inconsistency

Valid error correction at exactly 48 GT/s

§4.1.2.1 lets retimer-link receivers at ≤ 48 GT/s retrain on any Valid error; §5.11 requires single-error correction at 48 GT/s. Correcting at 48 GT/s satisfies both.

Derived §4.1.2.1, p.101 vs §5.11, p.253 · Electrical guide

Stale reference

§11.3 points to the wrong UHM section

It says the UHM DVSEC is in §9.5.3.36; in Revision 3.0 that is Runtime Link Test Control, and UHM is §9.5.3.40.

Derived §11.3, p.581 · Compliance guide

Not covered in depth: individual bump-map figures, every register bit outside the main ones, and Appendix B (AIB interoperability).
